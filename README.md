One funny, painfully honest line, as if it were the comment a developer left above fragile production code:

> `// I added sleep(500) in 2019 to fix a race condition. The race condition is still here. So is the sleep. Nobody remembers why 500.`

## Run it

```sh
python3 main.py
```

Writes the line (131 characters, one line) to `/output/entry.txt`. Pure Python standard library, no dependencies.
